# UIC WiCyS Website
This is the official website for the University of Illinois (UIC) chapter of Women in CyberSecurity. 
<hr />

To deploy:
1. Make sure all changes have been made and pulled into main.
2. Go into the main branch and run `npm run deploy`.
3. Wait for Vite to build and deploy to the `gh-pages` branch.
4. You are all set!
